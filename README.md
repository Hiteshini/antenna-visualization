# 📡 Antenna Radiation Patterns & Beamforming Visualization

This project visualizes antenna radiation patterns and beamforming using Python and `matplotlib`.

## 📈 Visualizations
- 📍 Isotropic Radiation Pattern (Polar)
- 🔺 Directional Pattern (Cosine)
- 🌐 3D Radiation Pattern
- 🎯 Beamforming using Linear Antenna Array

## 🧠 Concepts Covered
- **Radiation Pattern**: How antennas emit/receive energy in space
- **Beamforming**: Directing signals to a desired angle using multiple antennas
